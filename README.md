# Fishing Legend — Unity 6

Мобильный 3D-прототип игры о рыбалке для Android. Движок: Unity 6, версия 6000.0.23f1.

## Что заложено в стартовый проект
- процедурная 3D-сцена с берегом, водой, пирсом, деревьями и камнями;
- вид от первого лица и простое сенсорное управление;
- цикл рыбалки: заброс, ожидание поклёвки, подсечка, вываживание и улов;
- базовый интерфейс на русском языке;
- сцена Assets/Scenes/Main.unity указана в Build Settings.

## Открытие проекта
1. Установить Unity Hub и Unity Editor версии 6000.0.23f1 с Android Build Support, Android SDK & NDK Tools и OpenJDK.
2. Открыть эту папку через Unity Hub.
3. Дождаться импорта и запустить Assets/Scenes/Main.unity.

## Android APK через GitHub Actions
GitHub Actions проверяет структуру проекта. Для реальной сборки APK требуется лицензия Unity, доступная GitHub Actions:
1. В репозитории добавьте secret UNITY_LICENSE с лицензией Unity в формате, поддерживаемом GameCI.
2. В Settings → Secrets and variables → Actions → Variables добавьте UNITY_ANDROID_BUILD со значением true.
3. Запустите workflow Unity Android на вкладке Actions.

Без лицензии Unity CI не запускает экспорт APK, чтобы не показывать ложный успех и не падать на заведомо отсутствующей лицензии.

## Ассеты и качество
Сейчас сцена использует процедурные примитивы, чтобы проект был самодостаточным. Реалистичные модели рыбы, удочек, деревьев и окружения ещё нужно импортировать и проверить их лицензии. APK пока не заявляется как собранный.
