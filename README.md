# Fishing Legend — Android prototype

Мобильный 3D-прототип рыбалки на Godot 4. Стартовая сцена создаёт тестовый берег процедурно, без внешних ресурсов, чтобы проект можно было импортировать до загрузки художественных ассетов.

## Уже заложено в прототип

- 3D-сцена берега, вода, камыш, кусты, деревья и пирс из простых мешей.
- Вид от первого лица, перемещение WASD/стрелками на ПК, свайп для обзора на сенсорном экране.
- Цикл «заброс → ожидание → поклёвка → подсечка → вываживание → улов».
- Условное натяжение лески, обрыв при критической нагрузке.
- Четыре вида рыбы, вес улова, опыт, уровни, садок и продажа за серебро.
- Быстрое переключение наживки.
- Android export preset и GitHub Actions workflow.

## Сборка через GitHub Actions

Workflow `.github/workflows/android.yml` запускается на push, pull request и вручную. APK публикуется как артефакт `FishingLegend-Android-APK`.

## Ассеты

В стартовой версии используются примитивы Godot. При добавлении внешних моделей сохраняйте лицензию и ссылку на страницу конкретного набора:

- Poly Haven — https://polyhaven.com/
- Quaternius — https://quaternius.com/
- Kenney — https://kenney.nl/assets

## Ограничения текущей версии

Это ранний прототип, а не законченный аналог «Русской рыбалки 4». Пока нет импортированных реалистичных 3D-моделей, анимаций рыб, полноценного магазина, квестов, погодной симуляции, лодок, донатной валюты или проверки на физическом Android-устройстве. Не считайте APK проверенным, пока GitHub Actions не завершится успешно и файл не будет установлен и протестирован.
